Features

Everything a fresh page needs

Tokens, layout, typography, animations and components, all consistent across every Scybud product.

🎨

Design tokens

Colors, spacing, radius, motion and z index live in CSS custom properties that you can override.

🧱

Sidebar layout

Styles for a fixed 260px sidebar and a mobile drawer below 800px. You add the toggle script.

🔘

Buttons

Primary, secondary, pill and no background variants, plus a built in loading state with aria-busy.

🪟

Modals

Load modal markup from an HTML fragment at runtime and clear it again with closeModal.

🔍

Lightbox

Add one class to an image and it magnifies into a centered overlay with a smooth animation.

📭

Empty states

Build placeholder blocks for empty lists and feeds with a single function call.

Edit the design tokens on the left. Every component on the right reads them live. Flip the scope switch to apply your changes to this whole page.

          Quickstart
          
Running in under a minute

          
Link the stylesheets, import from the single entry file, and use the classes.

        

        

          
app.js


import { setButtonLoading, createEmptyState } from "https://ui.scybud.com/js/ui.js";

const button = document.querySelector(".btn-primary");
button.addEventListener("click", () => setButtonLoading(button, true));

createEmptyState({
  container: document.getElementById("feedContainer"),
  title: "Nothing here yet"
});
